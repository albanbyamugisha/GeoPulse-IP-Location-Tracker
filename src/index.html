    Under the hood

    How GeoPulse works

    IP geolocation estimates the likely geographic area associated with an internet connection. GeoPulse combines a geolocation API with an interactive map to make that estimate easy to explore.

    1. 01

      Enter an address

      Type a public IPv4 or IPv6 address, or use Find My IP to detect the public address your connection presents.

    2. 02

      Send the lookup

      The browser sends an HTTPS request to the ipinfo.io geolocation service. This project uses its public, keyless endpoint.

    3. 03

      Read the response

      The service returns available network details, place names, time zone, and approximate coordinates.

    4. 04

      Plot the estimate

      Valid coordinates are plotted with Leaflet on OpenStreetMap tiles, alongside the details the service returned.

    Key idea

    IP geolocation does not read a laptop’s GPS. It estimates where a network is registered or observed, so it cannot provide exact addresses or continuous movement tracking.

    Read this before presenting

    Accuracy and privacy, in plain language

    GeoPulse is designed to show what IP geolocation can and cannot tell us.

    What the estimate means

    Treat every result as an approximate network location, not a measured device position.

    • Accuracy varies with the address, network, ISP, and data provider.
    • Country or region estimates are often more reliable than city-level results; exact accuracy is not guaranteed.
    • A mapped point may be an ISP gateway, VPN exit, proxy, mobile carrier, or another network location.
    • GeoPulse cannot provide GPS-level accuracy or track movement over time.
    • Missing or invalid coordinates are reported as unavailable rather than invented.

    Real-world test: Find My IP returned Kampala while the laptop was physically in Mbarara. This demonstrates that IP-based location is an estimate and may not match the device's actual location.

    Privacy and responsible use

    This is a user-initiated lookup demonstration, not a tracking product.

    • The IP address you search is sent over HTTPS to the external ipinfo.io service.
    • Only the last five successful lookups are kept in this browser’s session storage and are cleared when the session ends.
    • Do not enter addresses you do not have permission to investigate, and avoid sharing sensitive information with untrusted services.
    • Use IP geolocation for learning, network diagnostics, and rough context — not for surveillance or claims about a person’s exact location.
